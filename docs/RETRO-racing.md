# 赛车任务踩坑复盘（只读调查 · 2026-11）

范围：能量赛车 / 长按加速 / 充能。不涉及淘金币。每条结论均带证据（会话 seq 经 session_event_read 核实原文，或代码 文件:行号）。
会话缩写：S2 = session-2ed097be-4f9a-4f2b-b743-4ce699e265d1（主战场，赛车全部在其中）。

## 已证伪清单

- 1 / 用「点击去逛」类任务充能，浏览+返回后指望能量立刻反映在按钮上 / 实际 6 个该类任务做完（蚂蚁庄园、蚂蚁森林、闪购、抽最高1万、蚂蚁新村、双11寻宝），按钮仍读 46，随后 5s 长按 46→46 无消耗 / 证据：S2 seq 2735；同类结论写入 utils/racing.py:181 / 结论：跳转类任务即使计数推进，能量到账也不反映在「剩余N能量」按钮上（见未定论 U1）。
- 2 / 低能量时（56）长按 3s 期望消耗能量 / 实际 56→56 纹丝不动 / 证据：S2 seq 2616 / 结论：按钮文案无「长按」时任何时长都白按，先充能。
- 3 / 静止停留等待「浏览N秒」类充能任务计时 / 实际 好物随心逛 静止 18s 计数不变，连续失败 2/2 被跳过 / 证据：S2 seq 4625；run_energy.py:4-5 注释 / 结论：浏览类必须持续滑动，静止白等。
- 4 / 用 OCR 读左上角数字当能量、不区分页面 / 实际 在赛车页把淘金币余额 12782 当成能量（12782→782→12792 乱跳） / 证据：S2 seq 3145、3150 / 结论：赛车页左上角是淘金币余额，不是能量。
- 5 / on_racing_page 用「read_energy 不为 None」判断在赛车页 / 实际 能量任务面板左上角也能读到数字，误判在赛车页，随后「找不到加速按钮」，1866 能量一轮没烧 / 证据：S2 seq 3127；修复补丁见 seq 3133 / 结论：页面判断必须看赛车页独有文案（升级赛车拿钱/松手开始加速升级/组队赢），utils/racing.py:79-89。
- 6 / 用 back 关闭「解锁新车轮」弹窗 / 实际 back 直接掉到淘宝首页 Welcome，且弹窗不进无障碍树（buttons: []，确认选择/点点轮/骨头轮 全部 None） / 证据：S2 seq 4760、4767 / 结论：这个弹窗不能用 back 关，会把页面带走。
- 7 / 充能后不点「立即领取」指望累计任务奖励自动到账 / 实际 能量 66 停留 188s 不动，累计奖励入口「立即领取 +1000」在面板上躺着没人点 / 证据：S2 seq 3044、3063 / 结论：累计奖励必须手动领取才转成能量。

## 时序不稳点

- 1 / 充能后按钮「剩余N能量」滞后，时长不定 / 现象：做完 2 个任务每 30s 读一次按钮，66 持续 188s（实际 OCR 已 866）；2919 做 3 任务后刷新仍读 1；3200 刷新才读到 881 / 证据：S2 seq 3044、2919、3200 / 修复方向：离开重进（refresh_racing）+ 左上角 OCR 复核。
- 2 / 活动页闲置 1-2 分钟自动重置/漂走，read_energy 反复返回 None / 证据：S2 seq 2810（总结）、2775、2893 / 修复方向：每步操作前 goto_racing 拉回，成本高。
- 3 / goto_racing 靠 back 试错（最多4次×2.5s），不保证回得来，兜底走「我的淘宝→领淘金币」 / 证据：utils/racing.py:92-116；S2 seq 2810 / 修复方向：改为按「去赚能量/去赚金币」入口直接定位。
- 4 / 起始能量频繁读成 None（不在赛车页/控件树没刷新） / 现象：2683、2735、2882、2893、3044 开头全是 None / 证据：各 seq 原文。
- 5 / 长按后只 sleep 2.5s 就读数，读数可能未稳定 / 现象：3145 第二轮读出 12792 > 上一轮 12782（实为误读淘金币余额） / 证据：S2 seq 3145、3150 / 修复方向：读数源按页面分流后再谈等待时长。
- 6 / 「解锁新车轮」弹窗出现时机不可预测（烧到里程碑才弹） / 证据：S2 seq 4705 / 修复方向：burn 循环每轮先 OCR 检查该弹窗（run_energy.py:127-133 close_dialog）。
- 7 / 淘宝不在前台时 goto_racing/open_panel 直接失败 / 现象：手机停在开发者选项页，打不开能量面板 / 证据：S2 seq 4598 / 修复方向：先 am start 拉起淘宝再导航。
