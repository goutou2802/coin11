### 5.11 停留时长：阶梯 + 记忆（不要写死）
用户原话：「第一次直接返回，没做完就加到5秒，再没做完再加到8秒」。
- 阶梯常量为显式表：`DWELL_LADDER_JUMP_S=(0,5,8)` / `VISIT_S=(5,8,8)` /
  `BROWSE_OFFSETS=(1,3,6)` / `PLAY_OFFSETS=(3,6,9)`，到顶（`DWELL_LADDER_TOP=2`）不再加。
- 判定「没做完」= **行还在 / 计数没推进**；**行消失 = 已完成，不许升档重试**（`slot-disappeared`）。
- 学到的高档位进 `state/secs_cache.json` 的 `level` 段（精确 key + `@family`），同族下轮直接起步。
- **成功一次就降一档**（最低 0 档），失败再升回去 —— 自我纠偏，防止某族永久多等。
- **停留计时锚定「落地确认」那一刻**，不是 tap 时刻（页面倒计时落地后才开始，否则 2 秒任务只等到 1 秒）。
- 保险丝：同一行一轮内最多升 2 档。

### 5.12 跳转返回：优先 am start，BACK 只作兜底
`am start -n com.taobao.taobao/com.taobao.tao.welcome.Welcome` 等价于「点一下淘宝图标」，
Android 会把淘宝 Task 整体提到前台、**保留栈内页面**，不用一层层退栈（对比 BACK 最多 6 次 × 0.8s），
也**不会改动被切走那个 App 的页面状态**。
- 落地要验：轮询 focus，落 `TMSActivity` = 已在面板；焦点在 `com.taobao.taobao` 包内但非面板
  → `am_early_stop`，停止等待但**仍需 BACK 回面板**；落不到淘宝 → 退回 BACK 阶梯，不许放弃。
- 证据字段：`am_start_cmd / am_start_ms / am_start_ok / am_early_stop / landed_activity / landed_pkg / back_fallback_used / focus_seq`。

## 七、血泪坑（务必记住）
1. **Windows 控制台是 GBK**：日志/提示里出现 `✔ ❌ ✅` 会抛 `UnicodeEncodeError` **把整轮打死**。所有脚本开头都要 `sys.stdout.reconfigure(errors="replace")`，日志内容也尽量用 ASCII 符号。
2. **截图成本由带宽决定**：手机1 当热点 1.6s／电脑当热点 2.9s／手机2 两跳 4s。所有"每轮耗时"分析都要先看这个。
3. **息屏/锁屏**：唤醒只发 `keyevent 224`（**永不发 26**，那是切换会按灭）；插电时 `svc power stayon true`；发现停在锁屏就 `StopRun` 停手等人（没有密码，绝不猜）。
4. **面板标题会被滚出屏幕**：`panel_ok` 要求"标题+≥3行"，滚屏后会误判"面板丢了"→ 恢复阶梯 `force-stop` → 死循环。已用粘性判据 + `just_scrolled` 修掉，改这块时别退回去。
5. **任务会被"换人"**：做完一条，同槽位可能顶上来另一条任务，槽位判据会把新计数记到旧任务头上（已加 `slot_name_changed` 证据，判定结果本身是对的）。
6. **网络**：校园网有客户端隔离（设备互访被封）；Windows 热点与上网共用一个 radio，比手机当热点更慢；adb 端口会变。
7. **dash 的用户输入**：设备下拉必须由后端 `state/devices.json` 动态生成（曾写死 IP，换网后两台都"跑不了"）；记住的是「手机1/手机2 标签」不是 IP。
   同一类**又踩了两处**（2026-11-04 修）：「自检 scan」和「一键运行脚本」两个按钮调 `/api/start` 时**没传 serial**，
   于是无视下拉、永远跑在默认设备上；日志切换按钮也写死了旧 IP（点一下就切到不存在的设备、整片空白）。
   现在：三个按钮都传 `serial: deviceSel()`，`logDev()` 会自愈（钉住的地址不在设备表就回到跟随下拉）。
8. **`CREATE_NO_WINDOW` 会让 PowerShell 吐 GBK**：给 dash 所有子进程加 `creationflags=_NO_WINDOW` 止住终端闪窗之后，
   PowerShell 的隐藏控制台代码页是系统 ANSI(GBK)，输出按 UTF-8 解就会把中文路径解成 U+FFFD ——
   接管来的 run 记了个不存在的 `--out`，面板日志永远 0 行。修法：PS 命令前加
   `[Console]::OutputEncoding=[System.Text.Encoding]::UTF8;`，并**严格 UTF-8 解、失败才退回 GBK**（不要用 `errors="replace"`）。
9. **dash 不能持有 auto.py 的 stdout 管道**：旧实现把 auto.py 的 stdout 挂在 dash 管道上，
   杀掉/崩溃 dash 会让 auto.py 的 `print(flush=True)` 阻塞或抛错 —— 真机事故：`run.log` 冻在 21:21:18、
   任务提前收尾。现在 stdout **重定向到 `<证据目录>/console.log`**，父子之间没有管道，dash 随便重启。
   注意 **spawn 前要先 `os.makedirs(out, exist_ok=True)`**：第一天第一轮时证据目录还不存在，
   直接 open 会失败并兜底成 DEVNULL，那一轮的实时日志就全丢了。
10. **`ext_app_installed` 不能缓存空集合**（见 5.14）。
11. **任务会被"换人"时不要重试**：阶梯升档只在「行还在 / 计数没推进」时进行；
    行消失（`slot-disappeared`）= 已完成，升档重试只会把新任务的计数记到旧任务头上。

## 十、监控面板（2026-11-04 大改，用户「不用命令行，功能都做进面板」）
- **【刷新设备地址】按钮**（设备下拉右边）+ 一个可选输入框：手机重启后「无线调试」的端口会变
  （5555 → 随机端口，IP 不变），点一下就会 `adb mdns services` + 历史地址 + 老端口逐个 `adb connect`
  并按机型认人，写回 `state/devices.json` 后**自动重绑面板的设备表，不用重启面板**。
  自动发现不了时（端口全新且 mDNS 被热点挡住），把手机「无线调试」那页显示的 `IP:端口` 粘进输入框再点即可。
  接口：`POST /api/refresh_devices {addr?}`；实测「正确地址 0.5s / 错地址回退 3.2s，两台都能认回来」。
- **实时日志**：`GET /api/stream` 是 SSE，**500ms 一帧**，只管 `logs/runs/pill_state`；
  实测「run.log 写入 → 帧里出现」中位 **463ms**。重数据（rounds/scans/scripts）仍走 3 秒 `/api/state`。
  前端 `EventSource`，不可用时自动降级回 3 秒轮询。
- **自动接管**：后台 daemon 线程每 **5 秒**扫一次，把**命令行起的** auto.py 认领进面板
  （实测 4.6~7.6 秒；进程结束后 ≤5 秒自动回到「空闲」，不留幽灵）。
  关键修复：命令行起的 auto.py **不带 `--out`**，写的是 `evidence/<日期>-auto`；
  而按设备算的 `out_dir` 是 `...-auto-手机N`——**那里面根本没有 run.log**，这才是「认领了却一直显示还没有日志」的真因
  （新增 `_guess_out_dir()` 反查真实目录）。
- **【App 自检】按钮**：点一下后台跑 `python auto.py --appcheck`（不带 `--serial`，两台一起），
  表格显示 名称/包名/已装/能做/原因 + 支付宝单列 + 「与上次比 新增/消失」；结果读 `state/apps.json`，
  **面板重启后仍能看到**。
- **轮数保险丝输入框**：默认 120，透传 `--max-rounds`。**别往下调太多**：
  实测第一页要约 40 轮才做空，保险丝太小会每次都卡在「刚做空、正要滚第二页」那一瞬，永远看不到第二页任务。
- **布局**：右栏改成 flex + 自身滚动；`轮次` 硬下限 300px、`正在执行` 硬下限 90px，
  「待教的地方/导航失败/最前操作记录/App 自检」默认收起成一行、展开后限高 160px 内部滚。
- **踩过的坑**：给 dash 的子进程加 `CREATE_NO_WINDOW`（止住终端闪窗）会让 PowerShell 改用 GBK 输出，
  按 UTF-8 解会把中文路径打成 U+FFFD → 必须在 PS 命令前加
  `[Console]::OutputEncoding=[System.Text.Encoding]::UTF8;` 并**严格 UTF-8 解、失败才退回 GBK**。
- **重启 dash 必须真正脱离会话**（`Start-Process … -WindowStyle Minimized`），否则子会话一退出面板跟着被杀。
  重启 10 秒后要再确认一次它还活着。
