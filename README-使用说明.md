# coin11 使用说明（一页速查）

1. 双击 `coin11\run.bat` —— 它会：起面板（http://127.0.0.1:8899）→ 打开浏览器 → 让面板自己挑一台在线手机跑一轮淘金币（30 分钟）。
   **设备不再写死**：面板按 `state/devices.json` / `adb devices` 认，换了网络端口变了也不用改脚本。
2. 面板上：进度块（今天成功/跳过/失败 + 最近一轮的真实读数）、设备状态、轮次表（可滚动）、日志。
3. 要停：面板【■ 全部停止】或【⏹ 停止本台】；要收工：面板【⏻ 关闭面板】（会停掉正在跑的一轮并退出）。
4. 旧轮次占地方：面板【记录管理】→ 勾选或「只保留最近 N 天」→ 删除。
5. 出问题先看面板日志；离线排查 `python coin11\auto.py --selftest`（不连手机，23 项）。

> 赛车能量活动已下线，默认不跑；要复出就把 `auto.py` 里的 `RACE_ENABLED` 改 True。
